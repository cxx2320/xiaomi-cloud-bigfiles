连接你的小米云盘

  1. 在浏览器打开 i.mi.com 并登录小米账号
  2. 按 F12 打开开发者工具 → Console → 输入 document.cookie 回车
  3. 复制输出的整段字符串粘贴到下面（需包含 serviceToken 和 userId）

仅在本机保存 Cookie 到 data/credentials.json（权限 600），不会上传到任何第三方。 接口为社区逆向的非官方接口，仅供个人备份分析使用。
